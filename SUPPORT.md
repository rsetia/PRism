# Support

Prism is an unreleased alpha maintained on a best-effort basis.

## Getting help

1. Read the [README](README.md), especially the security model and current
   limitations.
2. Search [existing issues](https://github.com/rsetia/PRism/issues).
3. If the problem is not covered, open a bug report or feature proposal using
   the repository's issue forms.

For a bug, include a minimal graph or reproduction, the exact commit or package
version, Node.js version, operating system, actual behavior, and expected
behavior. Remove credentials and private repository data from logs.

Only the latest commit on `main` is supported during the alpha. There is no
guaranteed response time and no private general-support channel.

## Security

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md). The security address is not a
general support channel.
